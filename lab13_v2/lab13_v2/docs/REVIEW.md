# Крос-рев'ю (Завдання 4)
Перевірено за вимогами завдання: (1) діаграма відповідає коду; (2) рішення усуває проблему з опису;
(3) раннер відтворює демонстраційний сценарій. Підставте імена студентів у шапці.

## Рев'ю Студента Б коду Студента А (Command)
| Перевірка | Результат |
|---|---|
| Діаграма `task1-command` відповідає коду (класи, поля, методи, модифікатори, зв'язки) | ✅ збігається |
| Кожне призначення — окремий об'єкт з `execute()/undo()` | ✅ |
| Черга + виконання медсестрою пізніше, у журналі видно хто й коли | ✅ (`[10:30:20] Медсестра Іваненко виконала…`) |
| Відкликання останнього невиконаного призначення | ✅ зникає з черги, лист не змінено |
| Сценарій: 3 призначення → відкликання → виконання → журнал | ✅ `runPrescriptions()` |
| Зауваження | `Nurse.undoLastExecuted()` є, але в сценарії не показаний — можна додати 1 виклик для демонстрації; `ExecutionRecord.time` зберігається рядком — у реальній системі краще `LocalTime`. |

## Рев'ю Студента А коду Студента Б (Chain of Responsibility)
| Перевірка | Результат |
|---|---|
| Діаграма `task2-chain` відповідає коду | ✅ збігається |
| Кожен рівень — окремий клас, або обробляє, або передає | ✅ |
| Порядок/склад ланцюга задається в рантаймі | ✅ `HotlineService.configure(...)` |
