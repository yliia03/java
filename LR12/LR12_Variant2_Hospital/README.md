# Лабораторна робота №12 — Варіант 2: Обласна лікарня
**Тема:** Структурні шаблони проєктування: Bridge, Composite, Flyweight.

## Вибір шаблонів та аргументація для захисту
1. **Завдання 1 (Медичні звіти) — Bridge (Міст):**
   - Розділено абстракцію (`MedicalReport`) та реалізацію (`ReportFormat`) через агрегацію. Додавання формату `CsvFormat` потребувало рівно **1 нового класу**.
2. **Завдання 2 (Структура лікарні і ліжковий фонд) — Composite (Компонувальник):**
   - Єдиний інтерфейс `HospitalUnit` для листка (`Bed`) і контейнера (`HospitalDivision`). Метод `getFreeBeds()` рекурсивно працює на будь-якій глибині вкладеності (включно з блоком інтенсивної терапії).
3. **Завдання 3 (Призначення препаратів) — Flyweight (Легковаговик):**
   - Внутрішній стан винесено в `MedicationType`, кешується через `MedicationFactory`. Зовнішній стан (пацієнт, доза, графік) зберігається в `Prescription`. У пам'яті створено лише **8 об'єктів препаратів** на **1000 призначень**.
